「여행 준비물」 모바일 앱(PWA)

조건을 고르면 필요한 준비물과 개수를 자동 계산하고, 체크 기록을 휴대폰에만 저장하는 여행 준비 앱

화면 구성

1. 조건 고르기

박 수 · 해외/국내 · 여름/겨울 · 혼자/아이동반

2. 진행 막대

완료 항목 수와 전체 항목 수를 표시

3. 분류별 목록

서류 · 전자기기 · 의류 · 세면 · 건강 · 기타

4. 직접 추가

품목명과 개수를 입력해 기타 목록에 추가

하단 고정 전체 초기화 하단 고정 설치 안내

기능 요구사항

기능입력처리·출력검증
조건 입력박 수, 지역, 계절, 동반자조건 저장 및 목록 재계산박 수 1 이상, 허용값만 사용
필터링규칙표와 조건항상 또는 조건 일치 항목 표시조건 6종만 사용
개수 계산박 수와 계산식숫자·일수·일수+1·올림(일수/2)1 이상 정수
체크행 터치상태·진행률 즉시 갱신한 줄 전체 터치
저장조건·체크·직접 추가localStorage 또는 IndexedDB 저장·복원서버 전송 금지
초기화버튼과 확인체크·직접 추가 항목 삭제확인 메시지 필수

설치와 오프라인

아이폰

Safari에서 열기 → 공유 → 홈 화면에 추가 → 추가

안드로이드

Chrome에서 열기 → 메뉴 → 홈 화면에 추가 또는 앱 설치

오프라인: manifest.webmanifest와 sw.js로 핵심 파일을 캐시한다. 최초 접속 후 인터넷이 없어도 계산, 체크, 저장, 초기화가 작동해야 한다.

테스트 체크리스트

  • 2박·해외·여름·혼자 조건이 저장된다.
  • 속옷·양말 3개, 상의 2개, 하의 1개로 계산된다.
  • 해외 전용 품목이 표시된다.
  • 국내에서 해외 전용 품목이 숨겨진다.
  • 여름·겨울 품목이 구분된다.
  • 아이동반 품목이 표시된다.
  • 행 전체 터치로 체크된다.
  • 재실행 후 체크 상태가 유지된다.
  • 직접 추가 항목이 저장된다.
  • 오프라인에서 핵심 기능이 작동한다.

범위 밖

로그인·회원가입·계정, 서버·클라우드 동기화, 개인정보 수집, 외부 API, 공동 편집·공유, 결제·광고·구독, 사진 인식, 일정·예약 관리, 다국어, 관리자 편집 화면, 외부 라이브러리·폰트

제작 요청 요약

  1. 순수 HTML·CSS·JavaScript로 PWA를 만든다.
  2. 파일은 index.html, manifest.webmanifest, sw.js, icons만 사용한다.
  3. 준비물 규칙은 하나의 데이터 배열에 모은다.
  4. 조건에 맞는 준비물과 개수를 표시한다.
  5. 행 전체 터치 체크, 진행률, 직접 추가, 휴대폰 저장을 제공한다.
  6. 초기화·설치 안내 버튼을 하단 고정한다.
  7. 아이폰·안드로이드 설치와 오프라인 실행을 지원한다.
  8. 테스트 10개를 확인한다.
